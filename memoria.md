## Glosario del dominio

| Término | Definición |
|---|---|
| Buyer | Usuario con rol de comprador (rol por defecto al registrarse) |
| Seller | Usuario con rol de vendedor activo por autoactivación (sin aprobación admin en el MVP) |
| SellerProfile | Documento de la colección `sellers`: `_id` propio, `ownerUserId` (dueño), `displayName`, `description`, `pickupPoint`, `status`, `version`, `createdAt`, `updatedAt`. Estados del Sprint 1: `PendingActivation` (transitorio, invisible en API‑008) y `Active` |
| Admin | Administrador con acceso total; nunca asignado desde el cliente |
| Product | Publicación propia de un vendedor: alimento con nombre, descripción, ingredientes, precio, existencias, categoría, imagen aprobada y estado; dueño derivado de perfil local |
| Offer (histórico) | Modelo de oferta hija de producto canónico: superado; no usar como unidad obligatoria de compra |
| ComparativeOptions | Resultados de búsqueda/filtros para comparar productos de distintos vendedores por ingredientes, precio y calificaciones disponibles |
| Order | Pedido de un único producto de vendedor con cantidad; precio/total server-side y efectivo al entregar |
| PaymentMethod | Método de pago; único valor permitido: `Cash` (efectivo presencial en UTTT) |
| DeliveryToken | Código/QR generado por el comprador para confirmar entrega física |
| AvailabilityStatus | Comprabilidad derivada de categoría activa ∧ publicación activa ∧ stock suficiente; distinguir pausa de agotamiento, sin horarios |
| OrderStatus | `Pending`, `Accepted`, `InPreparation`, `Ready`, `Delivered`, `Rejected`, `CancelledByBuyer` |
| jti | JWT ID — identificador único del token, usado como clave en la blacklist de Redis (`revoked:{jti}`) |
| SAS (histórico) | Shared Access Signature — URL temporal de Azure Blob usada antes del cambio a AWS (DEC-018); superado |
| Presigned URL | URL temporal firmada de la API de S3 generada por el backend con el Instance Profile de la EC2: PUT de escritura y GET de lectura; alcance mínimo (un objeto), TTL corto y sin claves al cliente |
| MediaAsset | Registro de una imagen en Amazon S3 con estado `PendingUpload`, `Approved` o `Rejected` |
| DeviceToken | Token FCM por dispositivo; se elimina si FCM lo rechaza |
| FCM | Firebase Cloud Messaging — canal único de notificaciones push, emitido por el backend con Admin SDK |
| Azure App Service | Entorno de cómputo oficial anterior en Azure; **superado por DEC-018**: hoy es EC2 t3.micro única con 2 réplicas Compose detrás de Nginx y EIP en `us-east-2` |
| correlationId | Identificador único de request, propagado en todos los logs del ciclo de vida |
